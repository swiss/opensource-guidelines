// unit was "usually an office" in one and "usually a federal office" in the
// other.
//
// The English lists are identical, but the translations are not -- the two
// documents cite different things, and a translator picked a different
// abbreviation for the same concept (German AV vs AO, DVS vs DOEDS). So the
// entries are tagged per consuming document rather than included wholesale.
// The per-language entry counts differ on purpose; see TRANSLATING.adoc.
//
// `[horizontal]` stays in the including document, immediately before the
// include -- the block attribute carries across the include and across the
// leading tag comment, and leaving it here would double it up.
//
// A few entries are emitted twice, once per tag: the two documents sort them
// differently and no single order satisfies both. They collapse as soon as the
// source lists are alphabetised.
