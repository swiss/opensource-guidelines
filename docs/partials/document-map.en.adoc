// The map of Art. 9 EMOTA documents, shared by Em002, Em002-1, Em002-5 and
// Em002-7. It lived as a PNG in three copies that had already drifted apart --
// they disagreed about the checklist file format and about the whole right-hand
// column -- which is why it is one file per language now. The caption and its
// figure number stay in the including document, because the number differs per
// document and Em002 includes the map twice.
//
// Categories are carried by the subgraph names as well as the fills, so the
// diagram needs no colour key: a reader who cannot tell the fills apart still
// knows which group each document is in.
//
// The original's second key was shape, not colour: square corners meant the DTI
// sector was responsible, rounded corners the FOBL. That is what the "(DTI
// sector)" and "(FOBL)" halves of the group names carry.
//
// Em002-7 is therefore grouped with the guidance documents, which is the band
// the original draws it in, and keeps the red procurement fill the original
// gives it. Colour is its subject, the group is who answers for it; putting it
// in the FOBL group said both at once, and got the second one wrong.
//
// Titles are the short form on purpose. The full ones are in the prose around
// every inclusion, and a four-line node label makes the graph wider than the A4
// content box.
//
// Do not add a `theme`, `themeVariables` or an `%%{init}%%` directive -- the
// palette comes from the document's own tokens. `classDef` is not a theme
// override and is fine.
